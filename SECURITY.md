
# Security Policy

## About This Repository

This repository contains public documentation for the GSMPHIL Free IMEI Checker.

It does not require or authorize access to private GSMPHIL systems, databases, APIs, or customer information.

## Supported Versions

Security reports concerning this public documentation repository are welcome.

## Reporting a Security Vulnerability

If you discover a security vulnerability related to GSMPHIL services, please report it through the official GSMPHIL website:

https://www.gsmphil.com/

Please do not publicly disclose sensitive vulnerabilities before they have been reviewed.

## Responsible Disclosure

When reporting security concerns:

- Do not access other users' accounts or information.
- Do not expose personal or customer information.
- Do not publish private API credentials.
- Do not attempt unauthorized access to internal systems.
- Provide enough information to help investigate the issue.

## Protecting Sensitive Information

Never commit the following information to this repository:

- API keys
- Authentication tokens
- Database credentials
- Customer records
- Private supplier information
- Internal service configurations
